# منظف ملفات CSV
## Python CSV Cleaner

**Portfolio Demo Project** | المستوى: **أساسي** | المؤلف: [Eng-7ussamEltayb](https://github.com/Eng-7ussamEltayb)

### الفكرة
أداة سطر أوامر لتنظيف ملفات CSV غير المرتبة: إزالة التكرار، تطبيع النصوص، تحويل التواريخ والمبالغ، وإخراج ملخص إحصائي.

### التقنيات
Python, pandas

### المميزات
- تنظيف الأعمدة والنصوص
- إزالة التكرار والقيم الفارغة
- ملخص حسب المدينة والمبالغ
- بيانات عينة جاهزة

### طريقة التشغيل
1. pip install -r requirements.txt
2. python cleaner.py
3. راجع الملف الناتج في output/clean_sales.csv

### هيكل المشروع
```
cleaner.py
sample_data/dirty_sales.csv
requirements.txt
README.md
```
